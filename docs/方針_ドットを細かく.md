# 方針：ドット絵を細かくする（2026/11/05 に検討・まだ決めていない・まだ作っていない）

いまの絵は 1マス 16 ドット（`TS = 16`・キャラも 16×16）。細かくする形を3つ、画像で見くらべた。

- `docs/img/dot_16_24_32.png` … 16（いま）・24・32 ドットで描きなおした例（木・花だん・道・トマト・キャラ）
- `docs/img/dot2x_rico.png` … **いまの1ドットを 2×2 の4ドットに分ける**案。制作者のキャラ（うさぎパーカー・うさ耳・うさぎのしっぽ・おだんご・触角ヘア・髪グレー・目は赤のキラキラ・口ちゅー・ほっぺなし）で、左から「いま」「4つに分けた（自動）」「4つに分けて少し手を入れた」

## いちばん気に入られている案：1ドットを4つに分ける
- まず `tools/art/scale2x.py` で 16→32 に分ける（Scale2x。ななめのギザギザだけ少しなめらかになる。見た目はほとんど変わらない）
- そのあと、増えたドットに手で描きこむ：目（まつげの線・黒目・光・下を明るく）・口・髪の流れ（明るい筋と暗い筋）・服の陰・トマトのつや・木の葉っぱのつぶ
- いまの形と雰囲気はそのままで、顔まわりの表情が出る。全部を描きなおすより楽

## 作るときに決めること・気をつけること
- どこから手を入れるか（キャラ → 作物 → 木や家、のように目につく物から少しずつ、が案）
- キャラは部品の組み合わせ（`data.js` の `CHAR`：BODY・HAIR・TOPS・BOTTOMS・SHOES と、v26/v34 以降の帽子・小物・前髪・目・口・ほっぺ）で、`renderChar` がその場で 16×16 を描いている。32 にするなら、部品ごとに 32 用の絵を持つか、16 で組み立ててから分けて描きこみを重ねるかを決める
- 画面に映るマスの数はそのままにする（1マスの大きさが2倍の細かさになるだけ）。描くピクセルが4倍になるので、スマホの電池と重さに気をつける（いまも毎秒60回・端末の倍率そのままで描いている）
- ほかの人にも同じ見た目で見えるように、絵は端末の中で作る（サーバーの変更はいらない見こみ）
