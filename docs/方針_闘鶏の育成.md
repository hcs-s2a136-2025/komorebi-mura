# 方針：こもれび闘鶏を「育成と果たし状」のゲームにする（2026/11/05 に決定・まだ作っていない）

友だち（遊んでいる人）の意見をもとに決めた。いまの闘鶏（v101・`world.tori101`）を、育成と対戦のゲームに作りなおす。
参考にしたのは人気の育成ゲームの「気持ちいいところ」だけで、名前や絵はまねしない。

## 1. 育成
- 1回5分くらい・12ターン。毎ターン「走りこみ・羽ばたき・つつき・休む・おさんぽ・ごはん」からえらぶ
- 練習はいまのタイミングのミニゲームを短くして使う（うまく押せるほど伸びる）
- 能力5つ：はやさ・持久力・脚力・根性・かしこさ
- 調子（絶好調〜絶不調）と体力。むりをすると練習が失敗する
- とちゅうでイベントが2〜3回。えらんだ答えでスキルがもらえる（レースで発動）
- 回数：1日（日本時間）3回まで無料。そのあとはスマホコイン5枚で1回、1日あと3回まで
- 育成するたびに少しずつ強くなる（能力には上限あり）

## 2. 育てる子（どっちもできる）
- 牧場にいる本物のにわとり（`world.animals` の chicken）をそのまま育てる
- 牧場で「たまごをかえす」と新しいひよこ。まっさらから育てて、生まれた子は牧場の家族になる

## 3. いま育てている子にやさしく（全部を最初からにしない）
- いまの強さ（もともとの力 10＋なかよし度×4＋きたえた分 `tr[ID]`）を5つの能力に分けて引きつぐ。総合力は同じか少し上
- なかよし度・ランキングの記録（`grank` の `tori`・にわとりごと）は消さない
- いちばん手をかけた子に称号「古株の名鶏」

## 4. 果たし状（対戦・ランキング重視）
- 村の人のにわとりをえらんで果たし状を送る（自分の子と作戦〈にげ・さき・さし・おいこみ〉を決めておく）
- 相手は受けるか断るか。留守なら次の welcome で届く（`DmHandler` の取っておき方が見本）
- **断ったときは何も起こらない**（送った人の手元から果たし状が消えるだけ。「にげた」などの表示もしない）
- 勝ち負けはサーバーが決める（能力・作戦・スキル・その日の調子・少しの運。種を決めて、どちらの画面でも同じレース）
- 勝ち負けで闘鶏ポイントが動き、ランキング（週・全期間）になる

## 5. レースはしっかり見せる
- 横に流れるコースを走る。序盤・中盤・最後の直線で場面が変わる
- スキルが出たら名前がぱっと出る。追いぬき・並びかけの演出、決着は写真判定もあり

## 6. 餌の種類（いまある作物とつなげて、かんたんに作れる）
- 作り方はどれも「ふつうの飼料1こ＋作物1こ → 3こ」。季節のちがう作物を2〜3つずつにして、1年中どれかで作れる

| 餌 | 伸びやすい能力 | 使える作物 |
|---|---|---|
| 青菜ペレット | はやさ | キャベツ・ほうれん草 |
| 雑穀ミックス | 持久力 | とうもろこし・かぼちゃ |
| プロテイン飼料 | 脚力 | じゃがいも（牧場でも買える） |
| にんじんスティック | 根性 | にんじん・カブ |
| 赤い実ブレンド | かしこさ | トマト・いちご・なす |

- 育成の「ごはん」で1こ食べさせると、その能力の練習が3ターン1.5倍。同じ餌が続くと効きが落ちる。子ごとに好きな餌がある（好きだと調子も上がる）
- 毎朝のえさ箱（v112）とサイロ（v32）は、いままでどおりふつうの飼料だけ

## 7. 賭けと賞金（「かけられた数×0.3」の読み方）
- 果たし状の勝負に、村の人がどっちが勝つか賭けられる（戦うふたりは自分の勝負に賭けられない）
- 勝った子の持ち主に、賭けられた合計の3割。残りの7割は当てた人で分ける。だれも賭けなければ賞金なし
- 賭けはカジノと同じく `gambleResult` を通す（番付・負けの上限）。お金を引くのはサーバーが OK を返してから
