# 自分の村を建てる（こもれび村をもう1つ作る）

こもれび村は、だれでも自分の村をもう1つ建てられます。
自分の村を建てると、村もキャラクターもイベントも全部べつの、独立した村になります。管理人室も自分のものです。
お金はかかりません（GitHub・Neon・Render の無料プランを使います）。

> むずかしそうに見えるけど、ボタンを押していくだけで、30分くらいでできます。

---

## 用意するもの

- **GitHub** のアカウント（https://github.com）
- **Neon** のアカウント（https://neon.com）…村のデータをしまっておくところ
- **Render** のアカウント（https://render.com）…村を動かしておくところ

どれも GitHub のアカウントでログインできます。

---

## 1. GitHub で村をコピーする（フォーク）

1. https://github.com/hcs-s2a136-2025/komorebi-mura を開く
2. 右上の **Fork** を押す
3. そのまま **Create fork** を押す

これで、自分のところに `komorebi-mura` のコピーができます。

## 2. Neon でデータベースを作る

1. Neon にログインして **New Project** を押す
2. 名前は何でもOK（例：`my-komorebi`）。地域は **Asia Pacific (Singapore)** などの近いところ
3. できたら **Connection string**（接続情報）を表示して、次の3つをメモする
   - ホスト（例：`ep-xxxx.ap-southeast-1.aws.neon.tech`）
   - データベース名（例：`neondb`）
   - ユーザー名とパスワード
4. メモから、次の形の文字を作っておく（これが `DATABASE_URL` になります）

```
jdbc:postgresql://<ホスト>/<データベース名>?sslmode=require
```

> パスワードは、ほかの人に見せたり、チャットに貼ったりしないでね。

## 3. Render で村を動かす

1. Render にログインして **New +** → **Blueprint** を押す
2. GitHub とつないで、さっきフォークした `komorebi-mura` を選ぶ
3. 環境変数（Environment Variables）を聞かれるので、次のように入れる

| 名前 | 入れるもの |
|---|---|
| `DATABASE_URL` | 2で作った `jdbc:postgresql://...` の文字 |
| `DATABASE_USER` | Neon のユーザー名 |
| `DATABASE_PASSWORD` | Neon のパスワード |
| `ADMIN_PASSWORD` | 管理人室のパスワード（自分で決める。長めに） |
| `INVITE_CODE` | 友達に教える合言葉（自分で決める） |

4. **Apply**（作成）を押して、5〜10分待つ
5. できあがると `https://○○○.onrender.com` のアドレスがもらえます。これが自分の村の入口です

> `INVITE_CODE` は、`komorebi` のままにしないでね。リポジトリはだれでも見られるので、知らない人が入れてしまいます。

## 4. 村に入ってみる

- `https://○○○.onrender.com` を開いて、招待コード（`INVITE_CODE`）を入れて参加する
- 管理人室は `https://○○○.onrender.com/admin`。ユーザー名は `admin`、パスワードは `ADMIN_PASSWORD`
- 友達には、村のアドレスと招待コードを教えてあげてね

## 知っておくこと

### 新しいアップデートを入れるには

もとの村（こもれび村）がアップデートしても、自分の村には自動では入りません。

1. GitHub で自分の `komorebi-mura` を開く
2. **Sync fork** → **Update branch** を押す

これで新しい版が取り込まれて、Render が自動で村を新しくしてくれます（5〜10分くらい）。

### キャラクターの引っ越し

キャラクターは村ごとに別です。持ち物ごと引っ越したいときは：

1. もとの村で、**設定** タブ →「セーブデータの保護」→ **ファイルに保存**
2. 自分の村で、**設定** タブ →「読み込む」→ **ファイルを選ぶ** で、さっきのファイルを選ぶ

### 無料プランのこと

- 15分だれも来ないと村が眠ります。次に開いたとき、起きるまで1分くらいかかります
- 無料枠の内容は変わることがあるので、ときどき公式ページを確かめてください

### こまったら

- 村が開かない：Render の画面の **Logs** に、理由が出ていることが多いです
- データが消える：`DATABASE_URL` が入っていないと、公開し直すたびに消えてしまいます。もう一度確かめてね
